# 00_WAKE_UP — Read this first

**What this is.** A pitch website for **Panache Academy** (an aviation, hospitality and tourism training institute in India). It was built to show the academy's owner a redesigned version of their current site (panacheacademy.com) and convince them to hire us to rebuild it. It is not their real site — it is our proposal.

**What it is technically.** A plain static website. No build step, no framework, no server-side code. Just HTML files, one CSS file, one JS file, images, logos, and a background video.

Open `index.html` in any modern browser and it works.

## What can rot over time

- **Google Maps iframe** — Google has changed the embed URL format twice in the past decade. If both maps go blank, replace with the current `maps.google.com/maps?output=embed` format.
- **Google Fonts CDN** — `fonts.googleapis.com` for Poppins + Inter. If Google ever kills the free CDN, the site falls back to system fonts (still readable).
- **Unsplash CDN** — not used at runtime (we downloaded all Unsplash photos into `images/` at build time). No live Unsplash calls anywhere.
- **GitHub Pages** — free tier, requires the repo to stay public.
- **Netlify** — free tier is generous but the account needs to stay active. If Netlify auto-deploy stops, GitHub Pages is still the fallback.

## Where to start (10-second bootstrap)

```powershell
cd "D:\03_Clients\01_Panache_Academy"
python -m http.server 5500
# Open http://localhost:5500 in browser
```

Or just double-click `index.html` — most modern browsers will open it correctly with `file://` URLs, though the Google Maps iframes and video may behave better under `http://`.
